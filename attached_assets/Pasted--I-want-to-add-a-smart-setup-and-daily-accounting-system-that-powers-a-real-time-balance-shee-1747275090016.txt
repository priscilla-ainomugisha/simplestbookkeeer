### ✅ 2. Store Daily Snapshots

Create a structure to track each day:

```ts

  date: "2025-05-15",
  opening: { cash: 5000, capital: 6000 },

    { type: "sale", amount: 2000 },
    { type: "expense", amount: 500 }
  ],
  closing: { cash: 6500, liabilities: 1000, equity: 6500 }
}
```

Save snapshots in localStorage or a `snapshots.json` object in code.
