### ✅ 1. Onboarding Setup Chat (First-Time Use)

* Detect if setup is complete via:

  ```ts
  const isSetupComplete = localStorage.getItem("setupComplete") === "true";
  ```

  1. "What's your starting cash?"

  ```ts
  const initialSetup = {
    cash: 5000,
    inventory: 2000,
    capital: 6000,
    liabilities: 1000,
    date: "2025-05-15"
  };
  localStorage.setItem("initialBalances", JSON.stringify(initialSetup));
  ```

### ✅ 2. Store Daily Snapshots

Create a structure to track each day:

```ts
{
  date: "2025-05-15",
  opening: { cash: 5000, capital: 6000 },
  transactions: [
    { type: "sale", amount: 2000 },
    { type: "expense", amount: 500 }
  ],
  closing: { cash: 6500, liabilities: 1000, equity: 6500 }
}
```

Save snapshots in localStorage or a `snapshots.json` object in code.

---

### ✅ 3. Handle Daily Reset

On app launch:

* Check if today's date exists in snapshots
* If not:

  * Use the previous day’s `closing` as today’s `opening`
  * Create a new entry for today

---

### ✅ 4. Update State from Daily Transactions

From chat messages like:

* “Sold tomatoes 1500”
* “Spent 300 on transport”
* “Borrowed 1000 from James”

Create a lightweight parser (regex or keyword matching) that extracts:

```ts
{ type: 'sale', amount: 1500, category: 'sales', item: 'tomatoes' }
```

Update today’s snapshot by:

* Adding transaction to `transactions[]`
* Recalculating:

  * `cash += sale` or `cash -= expense`
  * `liabilities += borrowed amount`
  * `retained earnings = cash - liabilities`
  * `total assets = cash + inventory`
  * `equity = capital + retained earnings`

Render the balance sheet from the **current day's `closing`** data.
